# FastResume Career Agent · 网站 MVP

这是一个无需安装依赖的静态演示网站，展示第一版核心闭环：

1. 查看解释清楚的岗位推荐；
2. 用户决定是否创建投递任务；
3. 打开官网岗位、由用户完成注册和最终提交；
4. 以“准备中 → 待官网注册 → 待官网提交 → 已投递 → 流程中/结果”追踪申请状态；
5. 按用途分层维护网申资料库：基础资料、教育证书、经历及国企/事业单位专用字段。
6. 在“可爱 / 简约 / 商务”三种界面风格之间切换；主题偏好保存在当前浏览器。
7. 首页提供官网核验的岗位数据位、每日求职打卡和 Offer 进度。
8. 打卡完成后会出现全屏 Offer 鼓励画面。

## 本地查看

只查看静态界面时可运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

所有岗位、公司和投递状态均为演示数据；网页使用浏览器本地存储保存演示任务状态和档案输入。演示版没有账户体系、加密存储或生产级数据安全能力，请勿录入真实身份证号、档案、亲属、健康或其他敏感信息。
